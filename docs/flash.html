Flash it in your browser

Get the Claude.ai usage dashboard onto a Cheap Yellow Display straight from Chrome or Edge over USB — no Arduino IDE, no PlatformIO, nothing to install.

Before you start: use desktop Chrome or Edge (Web Serial isn't supported on Firefox/Safari or mobile), and connect your CYD over USB. This overwrites whatever is currently on the board - after flashing, the device walks you through Wi-Fi setup on its own screen.

firmware-direct — CYD

Fully standalone - no PC required

The CYD talks to claude.ai directly and stores your session cookie encrypted on-device. After flashing, connect it to Wi-Fi and open http://claudeusage.local/ to enter your account details - see the cookie guide for where to find them.

Your browser doesn't support Web Serial - use desktop Chrome or Edge. This page needs to be loaded over HTTPS to flash (it already is here).
See the firmware-direct README for how the cookie is stored and secured.

firmware-direct — D1 mini + TFT Shield

Wemos/LOLIN D1 mini (ESP32 clone) + TFT 2.4" Touch Shield V1.0

Same standalone app as the CYD build above, ported to the 2.4" 320x240 ILI9341/XPT2046 touch shield on a D1-mini-footprint ESP32 board. Compiles clean, but hasn't been flashed to real hardware yet - some of the shield's pin assignments vary between "D1 mini ESP32" clone manufacturers, so display or touch may need a pin tweak on first boot.

Your browser doesn't support Web Serial - use desktop Chrome or Edge. This page needs to be loaded over HTTPS to flash (it already is here).
See the firmware-direct README for the pin-mapping caveat.

firmware-relay

Needs relay-server running on a PC

The CYD never touches your session cookie - it polls a small script (relay-server) that you run on your own computer, which holds the cookie instead. The display only shows live data while that script is running.

Your browser doesn't support Web Serial - use desktop Chrome or Edge. This page needs to be loaded over HTTPS to flash (it already is here).
See the relay-server README to set up the companion script first.
